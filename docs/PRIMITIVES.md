# Five primitives

SoT: [Designing Grok Bot](https://x.ai/news/designing-grok-bot)

| Object | Meaning | Where in this template |
|--------|---------|------------------------|
| **Bots** | Persistent roles with contracts | `roster/` |
| **Chats** | 1:1 or small group | Core Team · optional Extended |
| **Prompts** | Once · Skills · Routines | `skills/` · Routines per-Bot after earn |
| **Tools** | Shared capabilities | Box · connectors · Grok Build · Cloud Agents |
| **Artifacts** | Durable outputs | `workspace/` · see ARTIFACTS.md |

## Boundaries

- **Shared:** Tools + Skills (account / org)
- **Per-Bot:** memory, Routines, contract
- **Coordinator:** Chief routes; specialists own Artifacts
- **Caps:** keep Bot count low · ≤6 per group · hire only via BOTTLENECKS.md

## Reply shape

1. Lead with the Artifact path or decision.
2. Short status beats — not play-by-play.
3. Widget / attachment when form fits.
4. Chat is control; files are the bus.
