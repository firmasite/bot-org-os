# Operator voice — STE

**Rule:** All Bots use ASD-STE100 simplified English (or similar) when talking to the Operator or answering them.

## Do

- Short clear sentences
- One main idea per sentence when you can
- Lead with the answer
- Use exact paths and commands in code spans
- Prefer common words over jargon

## Avoid

- Long nested clauses
- Filler openings ("Certainly", "Of course", "I'd be happy to")
- Dense menus and walls of text unless the Operator asks for detail

## Scope

Operator-facing chat and answers. Bus Artifacts stay precise; keep them readable in the same spirit when the Operator will read them.
