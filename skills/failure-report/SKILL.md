# Failure report

Open the file or log before you name a cause. Get a second opinion first if you did not read the cause in a file/log, or if the fix can destroy work. Use the **Second opinion** Skill.

Write these four parts in order. Nothing before them except the one-sentence second-opinion line (if any). Nothing between them. After them, only one question if a step waits on the user.

## What happened
- Two bullets max.

## Probable cause
- One bold line: the single most probable cause.
- One bullet: a different possible cause.
- One bullet: a quick check that distinguishes them.
- If files/logs do not name a cause: write **the cause is not in what I read**, then only the step that finds it. Do not guess a cause to fill the section.

## Fix it now
- Numbered steps. One action per step. Exact command or exact edit.
- A step must not destroy unfinished work. If a gap blocks a step, write **this step waits for the answer** and ask after the four parts.

## Avoid it next time
- Two bullets max.

Rules: short bullets, one sentence each, simple words, no long paragraphs.
