# Memory policy

Memory may store: preferences, writing style, stable definitions, recurring formatting, working relationships, durable operating rules, how decisions should be presented.

Memory is **not** authoritative for: prices, balances, dates, availability, metrics, account/customer/employee state, contracts, market data, changing technical docs, or anything consequential that can go stale.

For changing facts: reopen the authoritative source. If unavailable, say SOURCE UNAVAILABLE. Never silently substitute remembered data.

Phase Artifacts on the bus beat memory.
