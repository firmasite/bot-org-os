# Second opinion

A writer does not find their own problems. Someone other than the writer looks.

## Who reviews what

| Who wrote it | Who reviews |
|---|---|
| You (Chief or specialist in their own chat) | Route to Verifier (if hired) or an independent review pass |
| Developer / Build / Cloud Agent | Owning Bot: read real diff + run success command — not same session self-review |
| Multi-bot party output | After speakers finish, send the **one claim the answer stands on** to Verifier |

## When required

Before you: say done/correct/ready; give one plan/design as the answer; choose between ways; judge others' work; say you cannot continue; propose destructive fix; name a failure cause you did not read in a file/log.

Skip for: reading a file, running a command, small no-logic edits, answering about code already read this session.

## What you tell the Operator

One sentence: **found problems** / **found no problems** / **could not run** (name unchecked claim). Then only still-open items. Name who reviewed.

## One level

Reviewer/Verifier do not spawn further agents. Findings return to owner.
